# Offer Versioning

Welcome to the **Offer Versioning** documentation.

**Versioning** is a controlled mechanism for modifying an existing offer by creating a **new version** instead of directly modifying its existing configuration.

The new version carries the proposed changes and is subject to the applicable **review and approval process**. The existing version is retained to provide **configuration history and traceability**.

Versioning provides a controlled way to introduce changes while ensuring that configurations that are not supported for modification remain unchanged.

## Why is Versioning Needed?

Versioning is used to:

- Provide a controlled mechanism for modifying an existing offer.
- Allow supported business configurations to be updated without recreating the offer.
- Prevent changes to configurations that are not supported for versioning.
- Maintain continuity between the existing and new offer versions.
- Provide traceability of changes made to the offer.
